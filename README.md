# Netflix3-JeanneHenrotte

This interactive web application allows users to manage their personal movie collection, search for new movies online, and organize customized keyword lists.

Main Features: 
- Collection Management: Easily view, add, edit, or delete movies from your personal list.
- Live Search: Explore and search for any movie using a connection to the TMDb database, then add it to your favorites.
- Keywords: Extract associated movie keywords, automatically clean them up, and build your own custom keyword list to filter your preferences.
- Local Storage: All your data (movies and keywords) is saved directly in your browser (localStorage), allowing you to keep your collection across visits.
